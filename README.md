# Missing Person

An interactive horror mystery website about the disappearance of Sarah Chen.

## About

Sarah Chen disappeared on March 15, 2019.

Her apartment was locked from the inside. Her phone was left behind, and no clear evidence of foul play was initially discovered.

This project lets the user investigate Sarah's digital traces through her diary, photographs, messages, and recovered police evidence.

As the user explores the website, the story becomes increasingly unsettling.

## Features

- 📓 Interactive diary entries
- 📷 Photo evidence
- 💬 Message conversations
- 🚨 Recovered police evidence
- 👁️ Hidden story elements
- ⚡ Glitch effects and animations
- 🔊 Simple browser-generated sound effects
- 🌑 Dark horror-themed interface
- 📱 Responsive layout

## Technologies

This project was built using:

- HTML
- CSS
- JavaScript
- Web Audio API

No frameworks or libraries are required.

## How to Run

Download or clone the project and open:

`index.html`

in a web browser.

Make sure the `assets` folder stays in the same directory as the HTML file.
