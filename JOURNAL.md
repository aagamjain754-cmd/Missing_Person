# Missing Person — Development Journal

## Project Overview

**Project:** Missing Person  
**Type:** Interactive horror mystery website  
**Technologies:** HTML, CSS, JavaScript  
**Total development time:** 5 hours  
**Development period:** 2 days

---

# Day 1 — 3 Hours

## Planning & Story — ~45 minutes

I started by planning the concept for my horror project.

I decided to make an interactive mystery about **Sarah Chen**, who disappears on March 15, 2019.

I planned the website around different pieces of information that the user could investigate:

- Home / case information
- Diary
- Photos
- Messages
- Police evidence

I wanted the story to become more disturbing as the user explored different sections rather than revealing the entire mystery immediately.

## HTML Structure — ~1 hour

I created the main HTML structure for the website.

I added the navigation buttons and separate sections for the Home, Diary, Photos, Messages and Police Evidence pages.

I also added the initial story content and Sarah's diary entries.

## Story & Content — ~1 hour 15 minutes

I wrote the diary entries and developed the mystery around Sarah hearing something outside her bedroom.

I also created the message conversation between Sarah and her mother and added the recovered audio evidence.

I added a hidden diary entry that is revealed when the user interacts with the page.

---

# Day 2 — 2 Hours

## Images & Assets — ~30 minutes

I created an `assets` folder and added the images used by the project.

I connected the images to the Photos section using relative paths so they work locally with the website.

## CSS & Visual Design — ~45 minutes

I worked on the visual style using CSS.

I created the dark horror-themed appearance and styled the navigation, diary entries, messages, evidence section and page transitions.

I also experimented with glitch effects, hover effects and animations to make the website feel less static.

## JavaScript & Interactions — ~45 minutes

I added JavaScript interactions to make the project interactive.

I implemented:

- Page navigation
- Hidden diary entry reveal
- Glitch effects
- Random unsettling messages
- Photo interactions
- Evidence-page scare event
- Simple Web Audio effects

I then tested the different sections and fixed issues that appeared during testing.

---

# Final Result

After approximately **5 hours of development across 2 days**, I created an interactive horror mystery website about the disappearance of Sarah Chen.

The user can explore Sarah's diary, photographs, messages and recovered police evidence while the website gradually becomes more unsettling.

## What I Learned

During this project I learned more about:

- HTML page structure
- CSS styling and animations
- JavaScript DOM manipulation
- JavaScript event handling
- Showing and hiding HTML elements
- Using images from an assets folder
- Creating simple browser audio effects
- Debugging HTML, CSS and JavaScript
- Combining storytelling with interactive web design

## Current Status

The main website and interactions are complete. I tested the pages, assets and interactive horror effects and made adjustments during development.
